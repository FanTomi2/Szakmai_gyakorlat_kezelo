# Szakmai_gyakorlat_kezelo
A Neumann János Egyetem hallgatóinak szakmai gyakorlatát kezelő webes felület


# DOCKER TELEÍTÉSHEZ:
### Előfeltétel:
-Docker Desktop telepítése és futtatása

**1. Terminál megnyitása a projekt gyökérmappájában**<br>
      (ahol a docker-compose.yml fájl található)<br>
**2. Futtatandó parancs:**
```
docker-compose up --build
```

### Elérhetősége az oldalnak:
-Frontend: **http://localhost:5173/**<br>
-Backend: **http://localhost:7064/api/Hallgatok/reszletes**<br>
**http://localhost:7064/api/Hallgatok/statisztika/dashboard**
